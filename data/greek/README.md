# Greek Besorah data

Official TAGNT/TBESG downloads and importer working files are written here by `python -m scripts.greek`. Those directories are gitignored.

The compact runtime preview in `preview/` is committed. `scripts/generate-static-data` copies it into `web/public/data` so Cloudflare Pages can serve Greek without the official 48 MB sources. Commands and recorded revisions are in `scripts/greek/README.md`.
